## Carolina Chedid Langaro

Neuroscience undergraduate interested in neural dynamics, timing, and learning,
with a focus on biologically grounded computational models.

### Selected Projects

  Minimal biologically motivated RNN showing emergent timing and omission responses.

- **Neuronal Spiking and Receptive Fields**
  Simulations of V1-like spiking neurons and orientation tuning.

- **40 Hz Gamma Analysis**
  Spectral and temporal analysis of gamma-band neural activity.

- **Barnes Maze Behavioural Analysis**
  Analysis pipeline for rodent spatial memory experiments.
