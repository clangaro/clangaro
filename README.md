## Carolina Langaro

Neuroscience undergraduate at UC Berkeley. I study why memory holds in some brains and fails in others with ageing and disease, using bench work, behaviour and computational models together.

### Projects

- **[sleap-analysis](https://github.com/clangaro/sleap-analysis)**: behavioural measures for mice in the Barnes maze and novel object recognition test, computed from SLEAP pose tracking. It records each mouse's search path as well as its escape time. Built in the Kriegsfeld Lab, UC Berkeley.
- **[pnn-cell-counter](https://github.com/clangaro/pnn-cell-counter)**: an object detector for counting parvalbumin-positive cells and perineuronal nets in confocal images of mouse brain sections. Work in progress.
- **[datawise-app](https://github.com/clangaro/datawise-app)**: a web app that guides researchers through choosing a statistical test, checking its assumptions and running it (React, FastAPI).

### Research

At the Laboratory of Neuro Imaging, USC, I work with Dr Ryan Cabeen and Professor Arthur Toga on whether brain-MRI classifiers of Parkinson's disease detect the disease or the scanner that took the scan. Manuscript in preparation.
